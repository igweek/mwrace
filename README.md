# mwrace

一个班级任务竞速小游戏。首页默认进入随机队伍模式，生成 5 个队伍，可以直接比赛；未登录数据只在当前页面里有效，不会保存到账号。

## 预览

直接打开 `index.html`。首页只显示比赛区、当前班级选择和历史总分；账号、班级、小组管理都在右上角“设置”里。

## Supabase 与 Vercel

完整部署步骤见 [DEPLOYMENT.md](DEPLOYMENT.md)。

1. 在 Supabase 新建项目。
2. 打开项目的 SQL Editor，执行 `supabase/schema.sql`。
3. 在 Authentication 中启用 Email 登录方式。
4. 部署到 Vercel 时，在环境变量里填写：
   - `SUPABASE_URL`
   - `SUPABASE_ANON_KEY`
5. 页面会通过 `/api/config` 自动读取环境变量，不会在界面展示 URL 或 key。

## 使用逻辑

- 未登录：随机 5 个游客队伍，可以比赛，但刷新后不会保存游客数据。
- 登录后：可以新增、改名、删除班级。
- 选中某个班级后，可以给该班级新增、改名、删除小组。
- 赛道只显示当前选中班级的小组。
- 小组的 `points` 是历史总分；下次登录并选中同一个班级后，会继续显示这些队伍和历史得分。
- “重开本轮”只重置当前赛道进度，不清空历史总分。
- “清空历史总分”会把当前班级所有小组积分置为 0。

## 数据模型

- `classes`：班级，按 `owner_id` 归属到当前用户。
- `groups`：小组，归属到班级和当前用户，包含角色编号、排序和历史总分。
- RLS 已在 `supabase/schema.sql` 中开启，用户只能访问自己的数据。
